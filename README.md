# Claude Code: Do Zero ao Desenvolvimento Profissional com IA

Curso gratuito da **Tchr**, para iniciantes e desenvolvedores. Roteiros de gravação em português, baseados na conversa fornecida pelo autor: **48 aulas, 8 módulos, 319 minutos estimados (5h19)**. O tempo de prática do aluno não está incluído.

## Como gravar

Abra o arquivo da aula pelo [índice da ementa](EMENTA.md). Cada roteiro contém preparação, cenas com tempo sugerido, falas para narração, comandos/prompts, conferência, exercício e cuidados técnicos. Leia primeiro a [direção de gravação](materiais/DIRECAO-DE-GRAVACAO.md). Os tempos são metas de edição: ensaie e corte esperas, sem acelerar explicações. As falas são texto para apresentar; instruções entre colchetes orientam a produção e não devem ser lidas.

**Criação sequencial:** os roteiros foram escritos e revisados na ordem das aulas. Os arquivos descrevem demonstrações a executar e ensaiar antes da gravação; não são registros de aulas já gravadas ou de respostas reais do Claude. Resultados da IA podem variar. Veja o [checklist editorial e técnico](CHECKLIST.md) para distinguir verificações realizadas das pendentes.

## Projeto que acompanha o aluno

1. Aulas 1–8: instalação, conta e uso seguro; nenhuma experiência em programação exigida.
2. Aulas 9–21: página Tchr Tarefas em HTML, CSS e JavaScript, evoluindo para tarefas em memória, contexto e revisão com Git.
3. Aulas 22–39: ferramentas, habilidades, workflows e qualidade no mesmo laboratório simples.
4. Aulas 40–45: reconstrução consciente do mesmo domínio com Next.js, TypeScript e PostgreSQL. Os recursos aprendidos são reaplicados; não se transforma automaticamente um HTML em aplicação full stack.
5. Aulas 46–48: consolidação e uso em equipe.

O primeiro projeto não precisa de framework ou servidor. Na aula 23 introduzimos Node.js e npm para o primeiro MCP; na aula 24, um servidor HTTP local para o Playwright. No projeto final, PostgreSQL local pode ser fornecido por Docker; quem não dispõe dele pode usar uma instância de desenvolvimento gerenciada. Nunca use produção para os exercícios.

O projeto final é um **laboratório de usuário único**, sem autenticação implementada nesta ementa. A publicação da aula 45 é uma demonstração em modo somente leitura, com dados fictícios. Um produto público com escrita e múltiplos usuários exige autenticação, autorização por usuário e proteção contra abuso antes do lançamento.
