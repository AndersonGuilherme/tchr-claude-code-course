# Glossário de apoio

| Termo | Explicação que pode ser usada na gravação |
|---|---|
| Terminal | Janela para conversar com programas usando comandos de texto. |
| Diretório/raiz | Pasta; a raiz do projeto é a pasta principal dele. |
| CLI | Programa controlado pelo terminal. |
| Editor/IDE | Ferramenta em que lemos e alteramos arquivos de código. |
| Prompt | Instrução enviada à IA, com objetivo, contexto e critérios. |
| Modelo | Sistema que produz as respostas da IA; há opções com capacidades e custos diferentes. |
| Token | Unidade usada pelo modelo para processar texto e outros conteúdos; não equivale sempre a uma palavra. |
| Contexto | Informações disponíveis ao modelo naquela interação. |
| Diff | Comparação que mostra linhas acrescentadas e removidas. |
| Commit | Registro de uma versão dos arquivos acompanhados pelo Git. |
| Branch | Linha de desenvolvimento no histórico do Git. |
| Worktree | Outro diretório de trabalho ligado ao mesmo repositório Git. |
| Dependência | Pacote externo de que um projeto ou ferramenta precisa. |
| Frontend | Interface que o aluno vê e usa no navegador. |
| Backend | Código que atende requisições e aplica regras no servidor. |
| API/endpoint | Forma de um programa pedir dados ou ações a outro; endpoint é um endereço dessa interface. |
| Banco/persistência | Armazenamento estruturado; persistir é manter os dados após encerrar uma execução. |
| HTTP/status | Protocolo de requisições na web e código que indica o resultado, como 200 ou 400. |
| Teste unitário | Verificação de uma pequena unidade de comportamento. |
| Teste de integração | Verificação de componentes trabalhando juntos, como API e banco. |
| E2E | Teste de ponta a ponta, reproduzindo uma jornada pela interface. |
| MCP | Protocolo que permite ao Claude utilizar ferramentas e fontes oferecidas por servidores compatíveis. |
| Skill | Instruções reutilizáveis que orientam uma tarefa; podem ter materiais auxiliares. |
| Subagent | Agente delegado para uma tarefa delimitada, com ferramentas e contexto próprios conforme a configuração. |
| Hook | Automação acionada por um evento do Claude Code. |
| Deploy | Publicação de uma versão em um ambiente acessível, com configuração própria. |
| Variável de ambiente | Configuração entregue ao programa pelo ambiente de execução. |
| Segredo | Credencial que dá acesso a um recurso e não deve estar no código público. |
