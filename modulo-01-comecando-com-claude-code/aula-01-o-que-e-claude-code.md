# Aula 01 — O que é Claude Code? Aprenda a programar com IA

**Módulo 1 · 5 min · Entrega:** explicar o papel do Claude Code e reconhecer uma alteração comprovada.

## Antes de gravar

Use uma conta de demonstração autenticada e uma pasta descartável com `index.html` contendo um título e um botão. O aluno ainda não precisa instalar nada. Deixe a página aberta no navegador e o arquivo no editor. Cena A: rosto; B: terminal/editor; C: navegador. Não prometa que qualquer prompt produzirá o mesmo código.

## Roteiro de gravação

### 0:00–0:30 · Gancho · A → C

**Fala:** “Nesta tela temos uma página simples. Eu vou pedir uma mudança em português, acompanhar o que a inteligência artificial faz e conferir o resultado. Esse é o ponto de partida do nosso curso: usar o Claude Code para construir software entendendo cada decisão. Você pode começar mesmo sem saber programar. Se já desenvolve, vamos avançar até testes, ferramentas e um projeto publicado.”

[Mostre o botão antes da alteração; mantenha-o na tela por três segundos.]

### 0:30–1:25 · Entenda · B

**Fala:** “Claude Code é uma ferramenta de desenvolvimento da Anthropic. Na demonstração, ele funciona no terminal, esta janela de comandos, e pode usar ferramentas para ler arquivos, propor mudanças e executar comandos conforme as permissões. Um chatbot também explica código, mas aqui estamos trabalhando sobre uma pasta real. O modelo produz respostas; as ferramentas permitem agir sobre o projeto. Essa diferença torna o trabalho útil e exige atenção.”

“HTML organiza o conteúdo de uma página; CSS cuida da aparência; JavaScript acrescenta comportamentos. Você vai aprender essas ideias aos poucos. Não precisa decorar agora. Sua primeira responsabilidade é reconhecer o pedido e verificar o que mudou.”

### 1:25–3:25 · Veja · B → C

[Na sessão já preparada, envie o prompt e leia-o em voz alta.]

```text
Leia index.html. Explique em duas frases o que existe.
Depois altere somente o texto do botão de "Começar" para "Minhas tarefas".
Não instale nada nem altere outros arquivos. Mostre o que mudou.
```

**Fala:** “Eu limitei a alteração a um arquivo e defini o resultado. Agora observo a leitura e a proposta de edição. Se aparecer uma permissão, leio a ação antes de aceitar. A resposta da IA não é a prova de que a página funciona: precisamos olhar o arquivo e abrir o resultado.”

[Mostre o trecho alterado; recarregue a página. Corte apenas a espera da resposta.]

“O botão agora diz ‘Minhas tarefas’. A mudança é pequena de propósito. Assim conseguimos ligar a instrução, o código e o resultado. Para quem já programa: revisão de diff e verificação independente continuam fazendo parte do trabalho; delegar a edição não transfere a responsabilidade técnica.”

### 3:25–4:25 · Confira · B/C

**Fala:** “Vamos conferir três coisas: o texto antigo desapareceu? O novo aparece? O restante da página continua igual? Se a IA disser que terminou e o navegador não mudar, verifico se abri o arquivo certo e atualizei a página. Não começo pedindo cinco outras mudanças.”

“A IA pode interpretar mal, inventar detalhes e produzir erros. Durante o curso vamos aprender a reduzir esses problemas com bons pedidos, planejamento, testes e revisão. A promessa é desenvolver com mais clareza, não eliminar a necessidade de pensar.”

### 4:25–5:00 · Pratique e transição · A

**Fala:** “Seu exercício agora é explicar em uma frase a diferença entre conversar sobre código e permitir que uma ferramenta altere arquivos. Uma boa resposta cita a ação sobre o projeto e a necessidade de conferir o resultado. Anote também uma mudança simples que gostaria de fazer nessa página. Na próxima aula vamos instalar a ferramenta para você acompanhar.”

## Conferência do professor

O take precisa mostrar o antes, a edição e o botão alterado. Se a conta não estiver disponível, regrave a demonstração depois; não apresente resposta inventada como execução. Apoio: [referências oficiais](../materiais/REFERENCIAS.md).
